# 排班台

一个纯前端的轮转排班工具，适合 20 人左右、7-8 个固定人数岗位的班组按周轮换。无需后台，数据保存在浏览器本地。

## 功能

- **周排班**：按人员顺序每周整体顺移一个位次，自动满足各岗位固定人数
- **岗位限制**：可指定某人只能上部分岗位，排班时自动避开
- **手动微调**：临时换岗只影响当周，下周继续按轮转顺序
- **月度总览**：按周查看整月岗位与休假分布
- **休假与台账**：登记调休/补休/年假/病假/事假，调休与补休可自动扣减台账额度，余额为负即欠休
- **告警**：岗位空缺、超编、待定人员、整周休假自动提示
- **导出**：复制本周排班文本、导出周/月 CSV、打印、JSON 备份与恢复
- **移动端适配**：手机上可直接打开使用

## 轮转规则

1. 每个岗位按需求人数展开成「位次」，例如前台 3 人 = 3 个位次；
2. 人员按顺序排列，每周整体后移 1 个位次，岗位人数不同，因此同一岗位通常连续 2-3 周；
3. 有岗位限制的人通过匹配算法分配，尽量贴近轮转位次；
4. 手动指定的岗位固定生效，只对当周有效，可在周排班页一键重置。

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
npm run preview
```

## 部署到 GitHub Pages

仓库已包含 `.github/workflows/deploy.yml`。推送到 `main` 分支后，在仓库 **Settings → Pages → Source** 中选择 **GitHub Actions**，等待 Actions 完成即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 数据说明

数据保存在浏览器 `localStorage`（键名 `paiban.data.v1`），不上传服务器。清理浏览器数据会丢失记录，建议定期在「数据」页导出 JSON 备份；换设备时导入即可恢复。
