# 排班台

一个纯前端的轮转排班工具，适合班组按周轮换排班。无需后台，数据保存在浏览器本地。只做电脑版。

## 功能

- **三栏控制台**：左侧人员树、中间班表网格、右侧告警与台账，一屏看全
- **拖拽调整**：拖动班表里的姓名换岗；拖人进格子＝安排上班；拖到「不在岗」＝当天休息
- **岗位组**：6 个岗位组（一号台 / 受理 / 校对扫描 / 照相 / 填表 / 机动），工作日与周六两套编制
- **值班组长**：组长是职务标签而非独立岗位，名字后标 ★，当天不在岗会告警
- **支援组**：周末支援组甲乙隔周各一组顶岗，平时在 512 柜台，不进本班表
- **月表**：按月查看每人的在岗、休假与休息天数，标注休息目标差额
- **休假与台账**：登记调休/补休/年假/病假/事假；周六值班自动 +1，调休与补休扣减额度，余额为负即欠休
- **告警**：在岗人数不足、组长位次空缺、欠休、休息不足分级提示（只提示，不影响排班）
- **内置节假日**：2026-01-01 ~ 2027-12-31 的法定放假与调休上班日
- **导出**：岗位表 CSV、人员月表 CSV、周文本、JSON 备份与恢复

## 轮转规则

1. 每个岗位组按当天编制展开成「位次」，空位次即缺岗；
2. 人员按顺序排列，轮转相位随日期推进（每天顺移一位，每周额外顺移一位），保证休息日分散；
3. 固定岗位人员优先锁定本岗，其余人按相位填满剩余位次；
4. 岗位受限的人通过匹配算法兜底；
5. 轮休人选依据固定顺序轮转，不因有人请假而整体漂移；
6. 手动拖拽只影响当天，可在班表页一键重置当周。

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
npm run preview
```

## 部署到 GitHub Pages

仓库已包含 `.github/workflows/deploy.yml`。推送到 `main` 分支后，在仓库 **Settings → Pages → Source** 中选择 **GitHub Actions**，等待 Actions 完成即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 数据说明

数据保存在浏览器 `localStorage`（键名 `paiban.data.v3`），不上传服务器。旧版本 `v1` / `v2` 的数据在首次打开时自动迁移到 `v3`。清理浏览器数据会丢失记录，建议定期在「导出」页导出 JSON 备份；换设备时导入即可恢复。
