# 排班台

一个纯前端的轮转排班工具，适合班组按周轮换排班。无需后台，数据保存在浏览器本地。只做电脑版。

## 功能

- **三栏控制台**：左侧人员树、中间班表网格、右侧告警与台账，一屏看全
- **拖拽调整**：拖动班表里的姓名换岗；拖人进格子＝安排上班；拖到「不在岗」＝当天休息
- **8 个岗位**：一号台 / 受理 / 校对 / 扫描 / 照相 / 填表 / 机动 / **512 柜台**（独立岗，不计入大厅在岗）
- **两套编制**：工作日（周一~周五）与周六 / 法定调休上班日各一套
- **值班组长**：4 人 —— 王玉花→杨娟→汪甜 逐日轮值管除 512 外的岗位，艾丽娜专管 512 柜台；组长是职务标签而非独立岗位，名字后标 ★
- **A/B 值班班组**：两组隔周交替承担周六与法定假日值班，整组上岗 8 人；B 组少 1 人时按 A 组名单顺序一人一次轮借
- **轮休额度**：周六与法定假日值班 1 天记 +1，登记调休 / 补休 1 天记 −N；额度当月休完，月末清零不结转
- **月表**：按月查看每人的在岗、休假与休息天数，标注休息目标差额
- **休假与台账**：登记调休/补休/年假/病假/事假，调休与补休扣减额度，余额为负即欠休
- **告警**：在岗人数不足、组长位次空缺、欠休、休息不足分级提示（只提示，不影响排班）
- **内置节假日**：2026-01-01 ~ 2027-12-31 的法定放假与调休上班日
- **导出**：岗位表 CSV、人员月表 CSV、周文本、JSON 备份与恢复

## 岗位编制

| 岗位 | 工作日 | 周六 / 法定调休上班日 |
|---|---|---|
| 一号台 | 1 | 2 |
| 受理 | 2 | 3 |
| 校对 | 2 | 0 |
| 扫描 | 1 | 0 |
| 照相 | 1 | 1 |
| 填表 | 1 | 2 |
| 机动 | 0~3 | 0 |
| 512 | 4 | 0 |

大厅核心位次 8 个，每日最少在岗 8 人。512 柜台是独立岗，工作日 4 人常驻，不与大厅岗位混排。

## 轮转规则

1. 每个岗位按当天编制展开成「位次」，空位次即缺岗；
2. 固定岗人员（周娟/贺夏炎→受理、颜贞贞→照相、杨雯→填表）锁定本岗；
3. 其余人进轮转池，**每周整体顺移一位**，一人一岗可持有一整周；
4. 轮转池里多出来的人进机动岗（0~3 人），机动负责临时顶替缺勤岗位；
5. 休假优先级最高，休假期间不排班；
6. 周六与法定调休上班日改由当值班组整组上岗，不再走工作日轮转；
7. 手动拖拽只影响当天，可在班表页一键重置当周。

## 本地运行

```bash
npm install
npm run dev
```

构建：

```bash
npm run build
npm run preview
```

## 部署到 GitHub Pages

仓库已包含 `.github/workflows/deploy.yml`。推送到 `main` 分支后，在仓库 **Settings → Pages → Source** 中选择 **GitHub Actions**，等待 Actions 完成即可通过 `https://<用户名>.github.io/<仓库名>/` 访问。

## 数据说明

数据保存在浏览器 `localStorage`（键名 `paiban.data.v4`），不上传服务器。旧版本 `v1` / `v2` / `v3` 的数据在首次打开时自动迁移到 `v4`。清理浏览器数据会丢失记录，建议定期在「导出」页导出 JSON 备份；换设备时导入即可恢复。
